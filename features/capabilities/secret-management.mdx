> The box keeps one store for secret material and delivers to each workload only the secrets it declares.

## What it gives you

- **One secret store** for the box's secret material.
- **Secret delivery** from the store to the workloads that declare them. Each managed cluster pulls only its own.
- **Cluster identity.** Each managed cluster has its own identity for reaching the secret store.
- **Platform-owned secrets.** The platform operator generates the secrets the platform's own services need.

## What you own

The values of your applications' secrets. You declare each one in git and supply its value once; see [Supply secrets](/quickstart/supply-secrets). The store's master keys are escrowed outside the box; see [Escrow](/features/admin/escrow).

## Built on

| Project | Role in your box | Runs on |
| :- | :- | :- |
| **Infisical** | The secret store | Management cluster |
| **External Secrets** | Delivers secrets from the store into each workload's namespace | Both cluster types |
| **Cluster identity operator** | Gives each managed cluster its identity with the management cluster | Management cluster |
| **Platform operator** | Generates platform-owned secrets and renders each managed cluster's configuration | Management cluster |
