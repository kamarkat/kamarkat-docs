> Your app builds commit to your GitOps repository with one token. Replace it with one command.

Each app's build publishes its chart, then commits the new version to your GitOps repository with `GITOPS_REPO_WRITE_TOKEN`. Scaffolding publishes that token on your git organization. Replace it when it expires, when it is disclosed, or when it lacks a permission your builds need.

## Step 1: Create the new token

In your git provider, create a token that can write to your GitOps repository.

## Step 2: Publish it

```bash
kakt tenant set-gitops-token --org acme-inc
```

The token is read from stdin, so it stays out of your shell history. Every repository in the git organization receives it, including ones created later.

<Warning>
On GitHub's free plan, organization secrets reach **public** repositories only, and a private repository's build receives an empty value. Publish per repository instead: `kakt tenant set-gitops-token --repo acme-inc/shop`, or let `--discover --gitops-repo acme-inc/acme-gitops-1794447136` find every repository whose workflows write to it.
</Warning>

## Step 3: Revoke the old token

Once a build has committed with the new one, revoke the old token in your git provider.
