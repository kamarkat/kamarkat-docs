---
title: "Rotate a secret"
description: "Supply the new value with the same command. The workloads that read it restart on the change."
keywords: ["rotate secret", "change secret", "kakt app secrets set", "credential rotation"]
---

> Rotating is supplying the value again.

## Step 1: Write the new value

```bash
kakt app secrets set dev shop PAYMENTS_API_KEY
```

Or, for several keys, `kakt app secrets import` with a file holding the new values. The old value is replaced.

## Step 2: Let it reach the app

The secret store delivers the new value within its refresh interval, and each workload that reads it restarts on the change. Nothing is committed: the declaration did not change.

## Step 3: Revoke the old value

Once the app runs with the new value, revoke the old one where it was issued.

<Note>
Each environment holds its own value. Rotate it in every environment the app is declared in.
</Note>

Platform credentials, such as database passwords, are generated and delivered by the box, and are not rotated with this command.
