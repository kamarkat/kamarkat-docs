> An environment is a directory per app, on a cell that already exists. Declare the cell first.

This guide adds `stg` to a box that runs `shop` in `dev`. The order matters: an app names the cell it runs on, and an app that names a cell that does not exist generates nothing.

## Before you start

**Choose the provider.** `hybrid` is supported for `dev` only. If your `dev` runs on `hybrid`, your `stg` and `prod` run on `hetzner`, so your environments are not all the same provider: the new one has cloud nodes and their cost, and no tailnet. See [Environments](/features/workloads/environments#providers-per-environment).

## Step 1: Declare the cell

Add a managed cluster for the environment, if it does not have one yet, and wait for it to converge. See [Add a managed cluster](/guides/add-a-managed-cluster).

Several apps in one environment can share a cell, so a second app in `stg` needs no second cluster.

## Step 2: Declare each app

For each app, create its directory in the new environment from the templates, as in the quickstart:

```bash
mkdir -p environments/stg/shop/frontend
cp templates/fleet/values.yaml environments/stg/shop/values.yaml
cp templates/workload/Chart.yaml environments/stg/shop/frontend/Chart.yaml
```

In `environments/stg/shop/values.yaml`, set what differs from `dev`:

```yaml environments/stg/shop/values.yaml
tenantId: acme
appId: shop
cellId: acme-stg-01      # the cell you declared in step 1

public:
  hosts:
    - shop.stg.acme.example
```

Declare the same `secrets` as in `dev`: the keys are the same, the values are not.

In each workload's `Chart.yaml`, set the version to promote. See [Promote between environments](/guides/promote-a-release).

## Step 3: Supply its secrets

Secrets are supplied per environment. Nothing is copied from `dev`.

```bash
kakt fleet secrets template stg shop > shop-stg.env   # the declared keys, with no values
# fill in shop-stg.env
kakt fleet secrets import stg shop --from-env shop-stg.env --confirm
kakt fleet secrets status stg shop
```

Or one at a time with `kakt fleet secrets set stg shop <KEY>`. Delete the `.env` file once the values are in your box.

## Step 4: Commit

```bash
git add environments/stg && git commit -m "Add shop to stg" && git push
```

The platform generates the app on its cell on the next pass. Every declared secret is checked before its workloads start, and a missing key is reported by name.
