> Kamarkat provides the platform. You own the box it runs in, and everything you build on it.

Kamarkat's part is the bundle: every platform component, its tested versions and defaults, the templates you start from, and the `soloz` CLI. Everything else is yours: your accounts, your GitOps repository, your clusters, your applications, and the use you make of every capability.

There is no third party. Kamarkat is built for teams without a platform team, so there is no split between a platform team and engineering teams: everything outside the bundle is yours.

Each row links to the page that describes it in detail.

## Git layer

| | Kamarkat | You |
| :- | :- | :- |
| **[Platform content](/features/box/bundle)** | Publishes each bundle version with its defaults | Choose the version each cluster runs |
| **[GitOps repository](/features/admin/git-connection)** | Provides the template it is scaffolded from | Own it: your values, cluster declarations and app declarations |
| **[Upgrades](/versions/upgrades)** | Publishes new versions | Your automation proposes them; you merge |
| **[Application repositories](/features/workloads/deploying-applications)** | Publishes the `platform-workload` library chart | Own your source, charts, images and CI |

## Infrastructure layer

| | Kamarkat | You |

| **[Cloud account](/features/admin/cloud-account)** | — | Own it, pay for it, hold its credentials |

## Application layer

| | Kamarkat | You |
| :- | :- | :- |
| **[Capabilities](/features/capabilities/overview)** | Ships each capability | Choose which to run, and own how you use them |
| **[Database](/features/capabilities/databases)** | Ships the engine and scheduled backups | Own the schema, migrations, queries and data |
| **[Identity](/features/capabilities/identity-management)** | Ships the identity provider and sign-in | Own your users and the clients your apps register |

## What you need to know

### The line is authorship, not location

A component belongs to Kamarkat when none of your logic is inside it. A database engine is Kamarkat's; the tables in it are yours. Where it runs does not change that.
