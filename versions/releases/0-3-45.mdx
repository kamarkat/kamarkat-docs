## What's included

Your box has one management cluster and the managed clusters it provisions. Each has control plane nodes and worker nodes. Choose a cluster, then a node role, to see what runs there. A version marked **unpinned** is installed at whatever version its source serves when a node is created.

**Latest (as of release date)** is the newest release the component's project had published on 23 Nov 2026. A version in green is that release; a version in red is behind it, or cannot be shown to match it. For an image the platform builds, latest is the newest build, and green means the version shipped it. Hover or focus the ⓘ beside a red version for why it is behind.
