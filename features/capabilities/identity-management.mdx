> One identity provider serves the box. Each application is its own project in your organization.

## What it gives you

- **One identity provider** for the box. Your organization is an organization in it.
- **A project per application,** with its clients created for you when the application is declared.
- **Token rules every application follows:**
  - An application's API accepts **access tokens**, never ID tokens.
  - An application calling another on its own behalf uses **client credentials**.
  - An application acting for a user carries **that user's own access token** for the target.

## What you own

Your users and the roles you give them.
