---
title: "Prepare the escrow"
description: "Create the escrow project your box's master keys and admin credential are kept in, outside the box."
---

Your box's secret store is encrypted by master keys. The box cannot keep them itself: they are what decrypts it, so they would be unreachable exactly when you need them. The escrow keeps a copy outside the box, in a secret manager you control and zero-ops does not.

The escrow also holds each cluster's admin kubeconfig, which you use only for [break-glass access](/quickstart/access-your-box#break-glass-access).

<Warning>
Without an escrow, losing the management cluster loses every secret the platform manages for it. You cannot add an escrow afterwards, so scaffolding refuses to continue without one.
</Warning>

## Step 1: Create an account and a machine identity

Create an account on the escrow secret manager (by default `https://app.infisical.com`), then create one **machine identity**. Note its client ID and client secret.

## Step 2: Create the escrow project

```bash
soloz escrow init \
  --client-id <machine-identity-client-id> \
  --client-secret <machine-identity-client-secret>
```

This creates the project your boxes escrow to and adds the machine identity to it as an admin. Use `--url` if your escrow is not at the default address.

## Step 3: Export the escrow values

```bash
export INFISICAL_ESCROW_URL=https://app.infisical.com
export INFISICAL_ESCROW_PROJECT_ID=<project-id>
export INFISICAL_ESCROW_CLIENT_ID=<machine-identity-client-id>
export INFISICAL_ESCROW_CLIENT_SECRET=<machine-identity-client-secret>
```

Keep these values somewhere safe outside the box. You need the same four to retrieve a kubeconfig in an emergency.
