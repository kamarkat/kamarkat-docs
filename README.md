# Kamarkat Documentation

Official documentation for zero-ops — an open-source platform a startup runs its business on, delivered into a box in its own cloud account.

Built with [Mintlify](https://mintlify.com).

## Local Development

Install the Mintlify CLI:

```bash
npm i -g mint
```

Run the development server from this directory:

```bash
mint dev
```

Preview locally at `http://localhost:3000` (or `http://localhost:3001` if port 3000 is occupied).
