---
title: "Remove a secret"
description: "Drop the key from the app's declaration and commit. The stored value stays in your box's secret store until you delete it there."
keywords: ["remove secret", "delete secret", "secrets", "declaration"]
---

> Remove the declaration first. The value is deleted separately.

## Step 1: Stop the app reading it

Change the app so nothing reads the key, and deploy that version. A workload that still reads a key you removed fails when it looks for it.

## Step 2: Remove the declaration

Delete the entry from `secrets` in the app's `values.yaml`:

```yaml environments/dev/shop/values.yaml
secrets:
  - name: PAYMENTS_API_KEY   # delete this entry
    capability: "the payment provider the BFF charges cards through"
    workloads: [bff]
```

```bash
git commit -am "shop: drop PAYMENTS_API_KEY" && git push
```

The key is no longer delivered to the app, and `kakt app secrets status` no longer lists it.

## Step 3: Delete the value

`kakt` writes secrets and never deletes them. The value stays in your box's secret store, under the app's path, until you delete it there.

Then revoke it where it was issued.
